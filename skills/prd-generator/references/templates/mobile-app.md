# 移动端 App 专项 PRD 模板

针对 iOS / Android 原生应用或跨端应用（React Native / Flutter）的专项 PRD 模板。

> 用法（DSH 版）：确认项目类型后读本文，把平台、导航、手势、推送、离线、性能指标、设备适配、商店审核、埋点等专项要求拆进 `features` / `non_functional` / `tech`，对应的机型与状态写进验收标准。
> prd.md 固定 9 章，不需要为模板另开章节：把下面检查项落到 `prd` 对象的对应字段即可。

---

## 专属章节

### 平台选择
- ✅ iOS (Swift / SwiftUI)
- ✅ Android (Kotlin / Jetpack Compose)
- ✅ 跨端：React Native / Flutter / UniApp

### 页面导航结构
```
启动页 → 登录/注册 → 首页
                      ├── Tab 1：功能 A
                      ├── Tab 2：功能 B
                      ├── Tab 3：功能 C
                      └── Tab 4：我的
```

### 核心交互模式
- **手势操作**：下拉刷新、左滑删除、双击点赞
- **推送通知**：分类、开关、免打扰时段
- **离线模式**：本地缓存、离线可用功能范围
- **深色模式**：跟随系统 / 手动切换

### 性能指标

| 指标 | 目标 |
|------|------|
| 冷启动时间 | < 2s |
| 页面切换流畅度 | 60fps |
| 包体积 | < 50MB |
| 内存峰值 | < 200MB |
| 崩溃率 | < 0.1% |

### 设备适配

| 设备类型 | 最低版本 | 屏幕尺寸 |
|---------|---------|----------|
| iPhone | iOS 15+ | SE ~ Pro Max |
| Android | Android 10+ | 主流分辨率 |

### App Store / 应用商店要求
- 隐私政策链接
- 权限使用说明（相机/位置/通知等）
- 审核时的测试账号
- IDFA / 数据收集声明

### 埋点与数据采集
- 用户行为埋点（页面曝光、按钮点击）
- 性能埋点（启动时间、接口耗时）
- 异常埋点（崩溃、错误）

### 升级与灰度
- 强制升级 / 可选升级
- 灰度发布策略
- 版本回滚方案
